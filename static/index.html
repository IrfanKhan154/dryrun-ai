How DryRun works

Four stages separate AI predictions from available evidence.

AI prediction

Vultr-hosted AI inspects the source and predicts potentially important behaviour.

02
Isolated execution

Docker runs the script with restricted resources and no network access. It still shares the host kernel.

03
Evidence collection

Capture program output. Event and outcome markers printed by submitted code are treated as untrusted.

04
AI vs Available Evidence

Compare predictions with available output and identify operations not independently verified.
